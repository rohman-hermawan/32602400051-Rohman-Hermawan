# InventoryHub

InventoryHub adalah aplikasi pengelolaan inventaris produk berbasis web yang dikembangkan menggunakan framework CodeIgniter 4. Aplikasi ini menerapkan konsep CRUD untuk membantu pengguna mengelola data produk secara terstruktur.

## Fitur Utama

- Login dan logout pengguna
- Menampilkan daftar produk
- Menambahkan produk baru
- Mengubah data produk
- Menghapus data produk
- Mengunggah gambar produk
- Menampilkan harga dan jumlah stok
- Pembagian hak akses berdasarkan role pengguna

## Hak Akses

### Admin

Admin memiliki akses untuk:

- Melihat daftar produk
- Menambahkan produk
- Mengedit produk
- Menghapus produk
- Mengunggah dan mengganti gambar produk

### User

User memiliki akses untuk:

- Login ke dalam aplikasi
- Melihat daftar produk
- Melihat harga dan stok produk

User tidak memiliki akses untuk menambahkan, mengubah, atau menghapus data produk.

## Teknologi yang Digunakan

- PHP
- CodeIgniter 4
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- Git dan GitHub

## Konsep yang Diterapkan

Aplikasi ini menggunakan pola arsitektur MVC:

- **Model** digunakan untuk mengelola data dari database.
- **View** digunakan untuk menampilkan antarmuka aplikasi.
- **Controller** digunakan untuk mengatur proses dan alur aplikasi.

## Struktur Fitur CRUD

- **Create**: menambahkan produk baru.
- **Read**: menampilkan daftar produk.
- **Update**: memperbarui data produk.
- **Delete**: menghapus data produk.

## Data Produk

Setiap produk memiliki beberapa informasi, yaitu:

- Nama produk
- Harga produk
- Jumlah stok
- Gambar produk
